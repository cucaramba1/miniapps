# Ресерч: откуда брать тренды и референсы IG + TikTok (05.11.2026)

Субагент-исследователь, 19 запросов. Даты коммитов взяты из GitHub API 05.11.2026. Помеченное «вывод» не проверено.

## Вывод
Бесплатно и стабильно можно получить только **ленты конкретных авторов** (instaloader / yt-dlp / gallery-dl для публичных профилей). **Поиска по слову или по идее без платного API или риска для аккаунта нет.** Поиск «описанием идеи» не заявлен нигде: делать свой индекс по подписям/хештегам собранных роликов и искать по смыслу локально (вывод).

## Просмотры без логина
- IG: plays у части Reels приходит `null` даже в платных скраперах. Один Apify-актор пишет, что с сентября 2026 IG требует логин для анонимных запросов (не подтверждено, слух). Вывод: на домашнем IP без логина нестабильно.
- TikTok: playCount публичный, отдают все инструменты (вывод).

## TikTok Creative Center
Доступность из РФ/Вьетнама и русский регион: не нашёл. По словам Apify-акторов, после редизайна 2026 остались только трендовые хештеги ([актор](https://apify.com/symphonic_mullite/tiktok-creative-center-trends)). Официального API нет. Для русской ниши знакомств скорее малополезен (вывод).

## Предложенные связки
**А, минимум риска:** платный API с бесплатными кредитами (ScrapeCreators/EnsembleData) для поиска и лент → список 20-50 авторов, ежедневно последние 12-20 видео → SQLite → outlier = просмотры / медиана последних N видео автора. yt-dlp запасной для TikTok.
**Б, ноль бюджета:** instaloader без логина с паузами + yt-dlp/gallery-dl по списку авторов; TikTokApi только если без него никак; IG hashtag search на отдельном бизнес-аккаунте, если пройдёт App Review. Аккаунт Полины в сборе данных не использовать.

## Не проверено
Цены ScrapeCreators и EnsembleData на официальных сайтах, расход кредитов на поиск, живой запуск библиотек, business_discovery.
