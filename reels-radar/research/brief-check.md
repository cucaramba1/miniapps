# Ресерч: проверка сценария по ТЗ (05.11.2026)

Субагент-исследователь, 4 веб-поиска. Проверено с URL только то, что в разделе «Проверено». Остальное это инференция модели, перед реализацией перепроверить (особенно флаги `claude -p`, pymorphy3, библиотеки мата).

## Вывод
Из ТЗ извлечь машинный чек-лист (JSON), генерировать сценарии в JSON-схеме, всё измеримое (длительность, фраза в первые 5 с, блоклист брендов, мат, CTA) проверять кодом. LLM-судья только для мягких пунктов (тон «не рекламно», негатив про онлайн-знакомства, политика/религия), лучше другой моделью. Цикл проверка → правка, не больше 2-3 итераций, потом показ с пометкой FAIL.

## Проверено (с URL)
- Темп речи: нормы не нашёл; встречается 120 слов/мин (≈2-2,5 слова/с). [HSE](https://publications.hse.ru/en/chapters/871422944), [Нетология](https://netology.ru/blog/12-2022-improving-public-speaking-skills). В рилсах говорят быстрее, калибровать по озвучкам Полины.
- Судья завышает оценки своих ответов (self-preference), смягчается судьёй из другой модели или панелью. [NeurIPS 2024](https://proceedings.neurips.cc/paper_files/paper/2024/file/7f1f0218e45f5414c79c0679633e47bc-Paper-Conference.pdf).
- IFEval: детерминированные проверки «проверяемых» инструкций, образец подхода. [evalscope](https://evalscope.readthedocs.io/en/latest/benchmarks/ifeval.html).
- Мат: `profanity-filter` (ru, репо архивировано, словарь из [djantimat](https://github.com/PixxxeL/djantimat)), `check-swear` (SVM + regex, транслит; свежесть не проверена). [PyPI profanity-filter](https://pypi.org/project/profanity-filter/1.1.6), [PyPI check-swear](https://pypi.org/project/check-swear).
- Не нашёл: готовых open-source чекеров brand safety для рилсов и генераторов сценариев с проверкой по брифу.

## Инференция (не проверено)
- ТЗ → `must[]`, `must_not[]`, `timing {max_sec, phrase, phrase_by_sec}`, `format`, `style`. Человек подтверждает чек-лист один раз на ТЗ.
- Сценарий в схеме `beats[{t_start, t_end, voiceover, on_screen, visual}]`, длительность считается по `voiceover`, цель 85% от лимита, пауза ~0,3 с на бит, числа разворачивать (num2words).
- Блоклист: нормализация (ё→е, транслит лат↔кир, повторы букв) + pymorphy3 + rapidfuzz (~85) + детектор «заглавное слово не из белого списка». CTA: regex на императивы.
- Судья: бинарная рубрика «да/нет + цитата», а не шкала 1-10. Правка получает конкретный список нарушений, после правки полная повторная проверка.
- Библиотеки: pydantic, rapidfuzz, pymorphy3, num2words. Guardrails AI / NeMo оверкилл для 8 ГБ. promptfoo только для регрессий на наборе ТЗ.
- Оценка: 10-15 ТЗ (реальные + ловушки), метрики hard-pass после ретраев (цель 100% показанных), с первой попытки ≥70%, false-pass судьи на ручной разметке ~30 сценариев, «звучит как автор» 1-5.

```
 ТЗ -> [1 extract: claude -p -> checklist.json] -> человек подтверждает
    -> [2 generate: claude -p + профиль персонажа -> scripts.json]
    -> [3 жёсткие проверки кодом] --FAIL--> список нарушений -> шаг 2 (макс 2-3)
    -> [4 мягкий судья: другая модель, бинарная рубрика] --FAIL--> шаг 2
    -> [5 повтор шага 3] -> показ (PASS) или показ с пометкой FAIL
```
