# Радар рилсов: план mini-app

Прототип: `index.html`. Данные трендов в прототипе выдуманные демо-примеры, форма данных повторяет то, что уже считает бот `reels-radar` (тема, суть, шаблон, цель).

## 1. Зачем
Сейчас Reels Radar это бот с очередью ревью и недельным дайджестом (`reels-radar/HANDOFF.md`). Mini-app даёт то, чего в чате неудобно: сетка трендов с метриками, структура ролика, адаптация под свою нишу, радар авторов. Ты просил что-то вроде Trendsee.

Развилка, которую нужно решить: это личный инструмент для Cucaramba TV или продукт для других. От ответа зависит, нужны ли оплата, регистрация и серьёзный бэкенд. В прототипе оплаты нет сознательно. Мой совет: сначала личный инструмент (три из четырёх экранов уже питаются твоими данными), продуктом делать после того, как он реально поможет вести канал.

**Интерфейс:** меню «Поиск контента» (Главная, Поиск по слову, Контент-радар, Шпионаж) и инструменты (анализ видео, анализ профиля), видно на демо-скриншоте лендинга. Поиск по слову с кнопкой «Добавить в радар», контент-радар обновляется раз в 3 дня, сортировка по просмотрам, лайкам, комментариям. Разбор: хук, длительность, текст на экране, музыка, монтаж, перевод. Сценарии с таймингом, приёмами съёмки, музыкой, призывом, три варианта хука и отмеченный триггер (страх, любопытство, жадность, принадлежность). Состав карточки тренда и фильтры не нашлись нигде, это за логином.

**Чего у них нет:** готового видео, монтажа, субтитров, озвучки. VPN нужен для просмотра видео внутри сервиса. Независимых отзывов нет, все найденные партнёрские; даже партнёры пишут, что сценарии надо дорабатывать и алгоритм иногда уходит в чужие ниши.

**Где можно выиграть:** интерфейс внутри Telegram без VPN, связка с очередью сохранёнок и Obsidian, и то, чего у Trendsee нет (субтитры и монтаж через твой стек). Если делать продуктом, ориентир цены ниже их 3 300 ₽.

## 3. Карта экранов
```
tab Поиск  ─> search ─┬─ По слову ─> результаты ─> «Добавить в радар»
                      └─ По ссылке ─> разбор (хук, структура, звук)
tab Тренды ─> trends ─┬─> [sheet: ниши], чипы Растёт / Аномалии / Новые
                      └─> trend ─┬─> adapt (ниша + формат -> сценарий -> копировать / в заметки)
                                 └─> сохранить в Obsidian, пересъёмка
tab Радар  ─> radar ──┬─> [sheet: добавить автора]
                      └─> author (график последних 6 рилсов, убрать)
tab Сохранёнки ─> inbox (карточка бота: ✅ ❌ ✏️ 🏷, смена цели через sheet)
tab Дайджест ─> digest (топ для использования сразу -> trend)
settings (дайджест, алерт на всплеск)
```

## 4. Кнопки
| Экран | Элемент | Результат |
|---|---|---|
| trends | поиск, чипы «Растёт»/«Новые», «Ниши» | фильтрация, пустое состояние со сбросом |
| trend | сохранить | иконка меняется, тост «Сохранено в Obsidian» |
| trend | Адаптировать (MainButton) | adapt |
| adapt | ниша, формат, Сгенерировать | скелетон 0.6 с, затем сценарий; копировать, в заметки |
| radar | ＋ Автор | sheet, пустой ввод отклоняется, ссылка превращается в @ник |
| author | Убрать | автор исчезает, возврат на радар |
| inbox | ✅ ❌ ✏️ 🏷 | запись, отклонение, правка, смена цели из пяти (заметка, рилс, Claude, продукт, другу) |
| inbox | пустая очередь | экран «Всё разобрано» со счётчиками |

## 5. Как это связано с ботом
Источник данных очереди ревью это `reels-radar/data/radar.db` (SQLite). Mini-app читает карточки и пишет статусы тем же путём, что кнопки бота, откат остаётся через `/rollback`. Тренды из внешнего мира это подпроект B (Threads, Reddit, TG-каналы, внешние тренды) из HANDOFF, его ещё нет, поэтому раздел «Тренды» в боевой версии пустой, пока он не сделан. Это важное ограничение.

Ресурсы: ноут на 8 ГБ, боты сейчас остановлены (launchd disabled). Любой новый сервис по правилам `~/Claude Code/CLAUDE.md`: лимит памяти в сторожe, очередь стартёра.

## 6. Тесты
`tests/e2e.mjs`: раскладка и контраст на трёх ширинах и двух темах, поиск и пустое состояние, фильтры по росту и нише, открытие тренда и сохранение, переход в адаптацию, проверка сгенерированного сценария (формат и ниша попали в текст), добавление и удаление автора, очередь ревью до пустого состояния, дайджест.

Не проверено: реальные данные, скорость на сотнях карточек (в сетке 6), видео-превью (в прототипе эмодзи), право на показ чужих видео.

## 7. Правовой риск
Показ и «пересъёмка» чужих рилсов упирается в правила платформ и авторские права. Твоя же заметка «Блог без лица на чужом контенте, схема и риски» это отмечает. Для публичного продукта хранить только метаданные и ссылки, не видео.
