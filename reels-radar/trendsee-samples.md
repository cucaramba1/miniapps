# Trendsee: образцы выдачи (04.11.2026), эталон для нашей адаптации

Снято в демо-кабинете. Тренд «Накричала на мужа» (333.1k просмотров, автор оригинала 96.5k подписчиков). Вводные для генерации: ниша «Психология отношений», цель «Рост подписчиков», «Буду в кадре: Да», ограничения «Нет», плюс мой текст про Полину (реалити про свидания, разбор анкет VK Знакомств, самоирония, парные форматы, 15-30 секунд, русский).

## 1. Адаптация тренда (5 токенов)
Сервис шёл так: «Loaded writing voice» → «Content creation skill loaded» → блок «Почему сработает на рост аудитории» (3 пункта) → документ-сценарий справа с кнопками «Хуки», «Переписать», «Очеловечить».
Структура сценария: название; суть адаптации одним абзацем; Хук 0-3 сек (кадр, текст на экране, камера, совет); Основная часть 3-15 сек (объект в кадре, реплики списком, камера, совет); Призыв к действию 15-20 сек (текст на экране, совет); Музыка (настроение, совет); Монтаж (сложность, совет). Подпись на экране: количество слов и секунд.
**Недостаток (для нас важный):** я просил 15-30 секунд, а он дал 325 слов, «108 секунд» по его же счётчику, при этом внутри таймкоды 0-20 секунд. То есть ограничение по длине не соблюдено. Нужен наш чек-лист до показа: длина, что реально снимаемо дома, голос персонажа.
Содержание: шутка про парня, который после ссоры делает абсурдные бытовые микро-дела (нюхает лавровый лист, гладит кота «с лицом профессора квантовой физики»). Без привязки к VK Знакомствам, хотя я её указывал.

## 2. Хуки (5 токенов): 5 вариантов
Формат варианта: Триггер (с названием: узнаваемая боль, разрыв шаблона, интрига, прямой вызов, психологическая польза с иронией) → Текстовый хук → Аудио-хук → Визуальный хук → Почему работает. В конце «Рекомендации по выбору» (какой для репостов, какой для экспертного блога).
Примеры текстовых хуков: «Выдала ему 10-минутную тираду про отношения. Его реакция через минуту:», «Я: в слезах и драме. Он: вошел в режим энергосбережения», «Что делают мужчины, когда на них накричали, но спорить страшно:», «Покажите мне хоть одного парня, который после ссоры ведет себя иначе», «Учебник по психологии: мужчины уходят в пещеру. Реальность:».
Полезно: у каждого хука отдельно текст на экране, звук и кадр, плюс названный триггер.

## 3. Разбор видео (5 токенов)
Ролик @sashayakut (2.7k подписчиков, 139.8k просмотров, ×63 к обычным, ER 0.06): «Когда заходишь на страницу бывшей через 30 минут после расставания».
Состав разбора: тема видео; язык; теги формата (POV, мем, слайды); «К каким нишам подойдёт» (юмор и скетчи, психология отношений, лайфстайл, маркетинг); транскрипция (кнопки «Обновить», копировать); «Суть»; «Структура» по секундам (0-3 POV-ситуация, 3-5 быстрая смена кадров под бит, 5-6 комичный финал); «Хук фраза / Визуальный хук / Текстовый хук»; «Воронка / Маркетинг: куда ведёт» (здесь: без призыва, работа на охват). Кнопки: «Обсудить с ИИ», «Создать карусель», «Лучшие посты» автора, значок «Шпионаж» (следить за автором).
Метрики ролика: просмотры, лайки, комментарии, репосты, ER.
Заметка: транскрипт у видео без речи пустой или неточный (подпись «Ты можешь записать мой номер…» это звук, а не текст).

## 4. Поиск (расширенный, 8 токенов вместо 40 на кнопке)
Запрос «разбор анкет», Instagram. Выдача «Загружено: 16 видео», в карточке просмотры и бейдж ×N. Кнопка «Добавить в радар» (слово встаёт в слежение). Подсказки «Рекомендуем для вашей ниши»: знакомства, свидание, дейтинг, разбор анкет.
**Качество:** шумно. По слову «разбор» попали ролики про собеседования, психологов, бизнес-ассистента, мало про анкеты знакомств. Вывод: нашему радару нужны фильтры по смыслу, а не только по слову в описании.
