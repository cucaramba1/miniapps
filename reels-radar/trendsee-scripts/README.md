# Скрипты замеров Trendsee (04-05.11.2026)

Одноразовые скрипты, на которых сняты цены и образцы выдачи (см. `../trendsee-insights.md`, `../trendsee-samples.md`).

Как запускать:
1. Chrome с профилем: `~/.playwright-profiles/trendsee`, флаг `--remote-debugging-port=9333`, войти в Trendsee вручную (через Telegram).
2. `node <скрипт>.mjs <аргументы>`; `playwright-core` берётся из `~/Claude Code/miniapps/tests/node_modules`.
3. В скриптах путь `dir` (куда пишутся скриншоты) указывает на scratchpad сессии, поменять на свою папку.

Что делает:
- `ai2.mjs "<запрос>" <тег> <Instagram|TikTok|Instagram и TikTok>`: ИИ-поиск, ждёт результата, пишет текст и скриншот.
- `menu.mjs "<пункт меню>" <тег>`: открыть раздел через меню (клик через evaluate, потому что плашка перекрывает).
- `gen.mjs`, `search.mjs`: адаптация тренда и расширенный поиск (04.11).
- `carousel.mjs` + `carsend.mjs`: карусель (текст, отправка). Дальше шаги руками или по аналогии.
- `spyadd.mjs`, `spyadd2.mjs`, `spyadd4.mjs`: добавить блогера в Шпионаж (внимание: тратит токены, 12 + 2 за новое видео).
- `niche.mjs`: платный «Анализ ниши» (10 токенов).
Внимание: все скрипты тратят токены демо; перед запуском смотреть цену на кнопке (реальная списывалась ниже заявленной).
