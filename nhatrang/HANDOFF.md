# HANDOFF: Нячанг Дом (платный Telegram mini-app по жилью)

Обновлено 04.11.2026 (вечер, после сборки v2). Главный продукт под цель $3000 в месяц. Этот файл самодостаточен: новая сессия читает его, `PLAN.md` и `COMPETITORS.md` и продолжает.

## Что это
Mini-app для русскоязычных, которые ищут жильё в Нячанге на короткий срок. Сырьё есть: скилл `nhatrang-rental-watch`, `../../nhatrang-search/listings.json` (93 записи, 11 прошли фильтр), `sources.json`, шаблоны переписки, база контактов риелторов Некита (выгрузить он пока не может).

## Что сделано (v2 MVP, 04.11.2026, план `tmp/plans/2026-11-04-nhatrang-dom-v2-mvp.md`)
Прототип 03-04.11 (15 экранов) лежит в `archive/prototype-v1.html`, сервером не отдаётся.
- **Сервер** `server/` (FastAPI + SQLite WAL, Python 3.12 через uv): авторизация по подписи `initData`, доступ по срокам (стек покупок и наград), места/поиск/ранжирование без влияния рекламы, индекс удобства, отзывы с проверкой (150 символов, 2-5 фото, геометка 150 м, лимиты, удержание сомнительных), фото с подписанными ссылками, бот-вебхук с модерацией (`/queue /revoke /grant /stats /refund /paysupport`), оплата Stars (идемпотентно), риелторы, «Свободно», флажки, избранное, районы. `cd server && UV_PROJECT_ENVIRONMENT=.venv uv run --python 3.12 pytest -q` даёт 121 зелёный.
- **Данные**: `tools/osm_import.py` (Overpass, разовый запуск руками, уже скачан `server/data/overpass.json`: 300 мест = 243 отеля, 27 апартаментов, 18 хостелов, 12 гостевых домов; 1255 точек бытовухи), `import_listings.py`, `import_csv.py` (риелторы, сигналы), `load_districts.py`, `seed_test.py`/`test_server.py` (тестовый сервер с поддельным ботом).
- **Фронт** `index.html` + `js/` (ванильный JS, Leaflet с cdnjs, весь текст из API через textContent): онбординг, Проверить (поиск, карта, районы, флажки), карточка места, отзыв, добавление места, Свободно, Риелторы, Избранное, Профиль, paywall со Stars.
- **Тесты** `../tests/nhatrang.mjs`: 276/276 (поток по экранам, утечка платного контента, XSS, отзыв 149/150, оплата paid/cancelled/failed, раскладка 360/390/430 × светлая/тёмная). Стресс `node stress.mjs nhatrang 40 60 8 3`: 2400 действий, 0 нарушений, 0 JS-ошибок, пик Chromium 2146 МБ. Файлы деплоя в `server/deploy/`.

## Ограничения и риски
- Правила Telegram (`core.telegram.org/bots/payments-stars`, `telegram.org/tos/bot-developers` п. 6.2): цифровые услуги в mini-app только за Stars, иначе риск потери показа мобильным. Stars россиянам покупать неудобно.
- Не проверено: условия Bybit для физлица, налоги и вывод Stars, курс Stars к рублю, реальный платёж, нагрузка на сервер (его нет).
- Рассылку сообщений хозяевам не автоматизировать (правило проекта и ограничение Claude Code): только после ручного отбора Некита.
- Ресурсы ноута 8 ГБ: любой новый бот, ночная задача или сервис по правилам `~/Claude Code/CLAUDE.md` (лимит памяти в сторожe, очередь стартёра, `claude -p` с `--strict-mcp-config`).

## Подводные камни инструментов
- Telegram MCP в сессии может быть отключён. Сервис можно поднять по `../tools/tg/README.md`, читать скриптами `tgcall.py` напрямую.
- Python heredoc с текстом вроде `rm...` может сработать на защиту от удаления: скрипты с таким текстом класть файлом через Write.
- Скриншоты и тесты запускать по одному, браузер до 2 ГБ памяти.
- Артефакт публиковать тем же URL, список файлов даёт `build_bundle.py`.
